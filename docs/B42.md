# AI Thoughts — Build 42

Target: **Project Zomboid Build 42.13+** (CharacterStat + server-authoritative MP).  
B41 flat layout is **not** supported.

## Install layout

```
DeepSeekThoughts/
  common/
  42/
    mod.info          # versionMin=42.13.0, version=2.0.0
    poster.png
    media/...
```

1. Copy/link `DeepSeekThoughts` into `Zomboid/mods/` (or Workshop path).
2. Enable **AI Thoughts** in the B42 mods list.
3. On host/dedicated: run the Python bridge.

## Bridge files (B42-safe)

Lua writes under `%UserProfile%/Zomboid/Lua/DeepSeekThoughts/`:

| File | Role |
|------|------|
| `outbox/request.txt` | Game → bridge (JSON body) |
| `inbox/response.txt` | Bridge → game |
| `status.txt` | Bridge status for F9 |
| `settings.txt` | In-game settings (no API keys) |

Python bridge prefers `.txt` and still accepts legacy `.json` for one release.

```bash
cd bridge
python deepseek_bridge.py
# or Bridge Launcher
```

Set `ZOMBOID_USER_DIR` if your Zomboid user folder is non-default.

## Compat layer

`DST_15_B42Compat.lua` wraps:

- Trait collection (string / CharacterTrait / descriptor)
- Panic / stress / nicotine withdrawal (`CharacterStat.NICOTINE_WITHDRAWAL`)
- Zombie attract: `addWorldSoundUnlessInvisible` → `addSound` fallback
- Sandbox: `SandboxVars.DeepSeekThoughts.*` first

## Sandbox translations

B42.15+ JSON: `Translate/EN/Sandbox.json`, `Translate/RU/Sandbox.json`.

## What did not change

- Mode B protocol (private thoughts + dialogue director + quiet small talk)
- No crafting/items — no craftRecipe migration needed

## Test checklist

1. Mod loads in B42 (no missing `42/` folder).
2. F9 opens settings; bridge status readable from `status.txt`.
3. Thought sticky appears (private) after calm/combat hooks.
4. Two players nearby: serious dialogue + quiet small talk subtitle.
5. Small talk does **not** attract zombies; serious dialogue does if sandbox flag on.
